# Rivr Desktop — Releases

Publika releaser och auto-update-feed (`latest.yml`) för **Rivr Desktop**.

Installerare och uppdaterings-metadata publiceras hit automatiskt av CI i det
privata källrepot [`rivr-io/rivr-desktop`](https://github.com/rivr-io/rivr-desktop).
Repot är publikt så att electron-updater kan läsa releaser utan inloggning —
klinikernas receptionsdatorer har inga GitHub-konton.

Senaste installern finns under **Releases**.
